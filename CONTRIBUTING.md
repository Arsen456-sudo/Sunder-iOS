# Contributing to Sunder development

This repository is independently maintained by Arsen456-sudo. Original SimpleX contribution
instructions remain in `docs/CONTRIBUTING.md` and apply when contributing upstream.
The original coding/structure guidance remains useful for work on this codebase.

- Explain the specific problem and proposed change. Preserve messaging, storage and
  encryption behavior when making presentation changes.
- Keep changes focused, preserve attribution, and record modification dates.
- Only contribute work you have the right to license under compatible terms. Identify
  third-party code/assets and their actual source, revision and required notices.
- Read `docs/fork/LICENSING.md` before including or changing existing graphics. Do not
  assume root AGPL coverage for every resource.
- State exactly what was built, tested, inspected, or left unverified. Do not claim a
  successful build, audit or device result that was not performed.
- Never commit credentials, signing material, personal databases or unredacted logs.
- Report ordinary fork-specific bugs here; do not redirect all fork users to upstream support.
- Read `SECURITY.md` before reporting a vulnerability; public issues are not a private channel.

This fork does not require signing the SimpleX CLA merely to contribute here.
Contributions submitted to the upstream project must follow its own process.
The upstream CLA workflow is guarded to run only in the original repository.
