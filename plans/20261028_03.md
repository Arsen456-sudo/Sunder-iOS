# Complete actionable iOS publication preparation

## Problem statement

The remaining original iOS wallpapers/badges/symbols/sounds have unresolved resource
rights, and inherited crowdfunding/support surfaces still remain. The private repository
also retains old media/history which must not be assumed safe to expose unchanged.

## Solution summary

Remove the remaining original bundled media and replace functional visuals with native
symbols and a cached procedural wallpaper tile, and sounds with newly synthesized PCM.
Remove upstream fundraising entry points while preserving real operator/badge attribution.
Scan reachable local Git history for defined secret indicators and prepare an explicit
iOS-focused clean source export without rewriting the private repository or publishing it.

## Detailed technical design

- Preserve wallpaper case IDs, palette/scale settings and user-supplied image handling;
  replace only preset resource lookup with one cached neutral dot tile drawn in UIKit.
- Preserve badge verification/type/expiry logic and use corresponding SF Symbols in both
  SwiftUI and UIKit attachment paths. Retain factual upstream badge identity, omit promotion.
- Replace custom checkmark resources with distinct standard sent/delivered symbols.
- Generate original low-amplitude PCM WAV call cues with source and hashes. Change only
  bundle extensions; call start/stop/cancellation/vibration logic remains unchanged.
- Remove crowdfunding banners/sheets/WhatsNew promotion and its obsolete views, leaving
  shared BannerCard/BannerDismissButton helpers needed by non-advertising cards intact.
- Route development/support links to Sunder; preserve operator/legal and protocol URLs.
- The export tool reads a committed Git tree, never ignored credentials/build artifacts;
  omits non-iOS frontends/SDKs, historical site/blog/media, the upstream test fixture suite
  and unreviewed binary media; retains runtime code, licenses, provenance and build inputs.
  Emit an exclusion/transformation manifest. Never overwrite an existing destination,
  delete original history, change GitHub visibility or claim a built IPA is cleared.
- Audit all reachable local refs for specified credential/private-key markers without
  storing matched secrets. Known public test fixtures are documented separately.

Threat model: prevent broken force-unwrapped image lookup, hidden delivery-status meaning,
spoofed badge verification, inaudible call cues, credential leakage in logs/exports and
unintended publication of original graphics/history. No protocol/identity/security relaxation.

## Implementation steps

1. Read affected product/spec/source and resource callers before changing them.
2. Replace active media callers, generate original cues, remove unused asset sets safely.
3. Remove promotions and adapt fork support destinations; regenerate offline notices.
4. Run scoped current/history credential review and inspect private remote metadata.
5. Add a deterministic, non-destructive iOS source exporter and prepare a local snapshot.
6. Update concept/product/spec/impact and publication records; perform two clean static
   review passes. Native compilation/device checks remain explicit external gates.
7. Commit/push the private branch and report the concrete snapshot and remaining gates.

Affected docs: product/views/{chat-list,chat,settings,call}.md, product/concepts.md,
spec/{state,impact}.md, spec/client/{chat-list,chat-view,navigation}.md,
spec/services/{theme,calls}.md, iOS README and publication checklist.

Additional reviewed scope: visible extension/permission captions are updated without
touching copyright or signing identities; SunderSourceRef selects accurate development
source navigation. Nine original embedded sample/avatar literals, including two shared
Haskell data constants, are replaced with a neutral PNG; surrounding code is unchanged.
