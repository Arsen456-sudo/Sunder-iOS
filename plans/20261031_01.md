# Three native navigation islands

## Problem
The chat has both a standard title and a trailing title item; UIKit groups the
main filter/compose items despite sharesBackground=false because SwiftUI keeps
them in one multi-item group. The chat title must be truly centered.

## Solution
Clear the ordinary title at its source for modern non-note chats. Move its
existing title UIBarButtonItem into a single fixed centerItemGroup using UIKit's
editor item style; keep avatar alone in its trailing group and native back intact.
Use ToolbarSpacer.fixed between the main filter and compose as the source-level
native group break. Keep stable leading/context/avatar identifiers for UIKit's
own transitions. Use the existing Change localization instead of Edit.

## Steps
1. Verify Apple APIs and current title/group ownership.
2. Remove duplicate title preference and configure native center/trailing groups.
3. Add a native toolbar group separator and reuse localized Change.
4. Keep notes/selection/secondary chats, action handlers and search unchanged.
5. Update docs/inventory and review ownership/repeated-layout behavior twice.
6. Compile the exact commit in CI; device layout/transition checks remain separate.

Threat model: presentation-only; no message/account/network/storage changes.
Do not mutate another screen's navigation item or duplicate native back actions.
Plan review 1: item group ownership is singular per UIKit documentation.
Plan review 2: cache single-item groups, update only when identities change;
no timers, snapshots or custom animation code.

## Review corrections and checks
The modern title preference is cleared where originally set, not through an outer
modifier. UIKit's editor style exposes native center groups. Single-item cached
groups preserve the context identifier even while changing placement. Cleanup only
restores owned center/style state when still top, avoiding changes to an outgoing
pop transition or another screen. Avatar contains only the requested image.

Review 1: checked API availability, item ownership, selection cleanup, notes and
all original profile/context actions; corrected stale title and multi-item sharing.
Review 2: no new source/action or ownership issue found. No custom animations,
network, storage or navigation delegate changes. All 17 Change translations checked.
CI compilation and actual iPhone centering/push/pop checks remain to be performed.

The SwiftUI toolbar role is also editor for this native center-group layout, so
the framework and UIKit item style agree. Legacy/selection routes restore the
automatic role on supported systems; iOS 15 keeps its unchanged fallback.
