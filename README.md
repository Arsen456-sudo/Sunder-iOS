# Sunder iOS source

Independent client based on [SimpleX Chat](https://github.com/simplex-chat/simplex-chat),
without affiliation or endorsement by SimpleX Chat Ltd. Original authors' rights
and notices remain in [LICENSE](LICENSE) and [NOTICE.md](NOTICE.md).

This is an iOS-focused source snapshot. See [SOURCE_SNAPSHOT.md](SOURCE_SNAPSHOT.md)
for scope and [SOURCE_EXPORT.json](SOURCE_EXPORT.json) for source revision, hashes
and omissions. Android/Desktop, web/SDK clients, historical promotional material
and the upstream test/fixture suite remain outside this focused snapshot.

The iOS app uses native symbols, a neutral procedural preset texture, temporary
plain icon slots and original synthesized call cues. Custom user media support remains.
Read [iOS development instructions](apps/ios/README.md) and [dependency evidence](docs/fork/ios/README.md).

No compiled IPA or working-build guarantee is included. Own signing/Keychain/App Groups,
native-library provenance, complete binary notices and device checks remain binary-release
requirements. Set SunderRepositoryURL and SunderSourceRef in the iOS Info.plist and regenerate notices
before distributing a binary. Original operator conditions remain in [PRIVACY.md](PRIVACY.md).
