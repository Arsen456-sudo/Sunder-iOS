# Security reporting for Sunder development

This is an unofficial development copy. Preparation changes do not constitute an
independent security audit or a production-support commitment.

## Fork-specific vulnerabilities

A dedicated private reporting contact is not configured yet. Do not disclose vulnerability
details, credentials, exploit material or personal data in public issues. If a private
channel with the maintainer is already established, use it; otherwise request a private
channel without disclosing the vulnerability. Do not assume GitHub private reporting is enabled.

Configuring a private channel is recorded as an open project-readiness item. No address
or response-time promise is invented by this document.

## Issues also affecting original SimpleX Chat

Follow `docs/SECURITY.md`: report privately to chat@simplex.chat, preferably encrypted
using their published key. Do not send fork-only support requests or publicly disclose
unreleased vulnerabilities on behalf of the upstream team.

## Ordinary bugs

Use this repository for non-security fork bugs. Redact screenshots and diagnostic files;
never submit message databases, recovery material or account credentials.
